## 🌟 Featured Projects

### [Dascet](https://github.com/tomie-s/dascet) — Financial Tool Discovery Platform
> *Helping Canadians find the right financial products for their life stage and goals*

A full-stack fintech platform built independently from the ground up. Features a quiz-based matching algorithm, user tool lists, ratings & reviews, and a community contributor model.

`React.js` `TypeScript` `Supabase` `PostgreSQL` `Tailwind CSS` `Vitest`

---

### [FinLingo](https://finlingo-app.netlify.app) — Financial Jargon Explainer
> *Plain-English explanations of financial terms and documents, powered by AI*

Paste any financial text — mortgage clause, credit card T&Cs, bank statement — and get a plain-English breakdown plus follow-up questions to take to your financial advisor. Built with a custom `useFinLingo` hook handling API state, loading, and error. Designed to eventually integrate into Dascet as a core utility.

`React 19` `TypeScript` `Tailwind CSS` `Gemini API` `Vitest` `React Testing Library`

---

### [Flight Deals Tracker](https://github.com/tomie-s/day-39-flight-deals) — Price Alert Automation
> *Monitors flight prices and sends email alerts when deals hit your target price*

A Python automation tool integrating three external APIs — Amadeus for flight search, Sheety for managing destination lists in Google Sheets, and SMTP for email notifications. Handles both direct and connecting flight searches automatically.

`Python` `Amadeus API` `Sheety API` `SMTP` `REST APIs`

---

### [Weather App](https://github.com/AcademyCapstones/cohort-7-weatherapp-capstone-c7-s1-team-09) — Team Capstone
> *Full-stack weather app with city search and live conditions*

Built collaboratively as a team capstone at Promineo Tech. Demonstrated collaborative Git workflow, REST API integration, and full-stack Java development with Spring Boot.

`Java` `Spring Boot` `OpenWeatherMap API` `Maven`
